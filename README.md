# maheshjillelaportfolio

Build My Interactive Frontend Developer Portfolio

Build a premium, highly interactive personal portfolio website for me based entirely on the resume I provide with this prompt.

The resume is the source of truth for my personal information, experience, projects, skills, education, achievements, and technologies. Do not invent companies, projects, experience, achievements, metrics, job titles, or technologies that are not supported by my resume.

I am a Frontend / Software Engineer with strong React, JavaScript, PixiJS, animation, interactive UI, and WebGL-related experience.

I don't want a generic developer portfolio.
